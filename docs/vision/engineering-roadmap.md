## Evidence gates

Every milestone must address correctness, performance, architecture, resilience, reproducibility. Performance evidence must state the workload and separate compilation, execution, memory and code size where applicable. A platform matrix entry is confirmed only by an actual run. Research experiments must declare their supported subset.

## Current implementation package

M01/M03/M04/M05/M06 now include scalar normative conformance, reusable bounded analyses, interprocedural total-call elimination, canonical IR snapshots, transactional preservation checks, failure records, structural diffs and isolated pass replay. M43/M44 gain intermediate-pass execution and snapshot fuzzing. See [analysis and replay](../compiler/analysis-and-replay.md) and [semantics](../language/specification.md).

## Next vertical milestone: semantic and memory foundations

1. Introduce versioned type descriptors and define scalar/reference representation, object identity and nullability.
2. Implement a bounded heap with explicit roots and a baseline tracing collector; independently model reachability.
3. Add one complete string/array/structure path through syntax, resolution, typed IR, verifier, bytecode and AST/VM/JIT.
4. Extend the portable format and embedding ABI with declared compatibility rather than treating handles as integers.
5. Stress references across calls, allocations, collection, cancellation and host lifetime transitions.
6. Extend the normative corpus and differential/fuzz suites before enabling optimizations involving memory.

M02 still needs a justified typed-HIR boundary; M03 needs alias, branch-sensitive range and escape analyses; M06 needs failure reduction. GC stack maps, global allocation, tier transitions, FFI, query caching and additional targets remain distinct later deliverables.
